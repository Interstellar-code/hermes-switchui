# v2.5.18 — Canonical agent memory tabs

**Released:** 2026-07-19
**Type:** patch (memory UI fix)

## Problem

The Agent Memory pane showed only `SOUL.md` for Hermes Switch. When `USER.md` was exposed from the profile root, it displayed an unused bootstrap placeholder rather than the populated user profile injected by Hermes Agent.

## Root cause

SwitchUI read agent files from inconsistent locations. Hermes Agent treats each named profile as its own `HERMES_HOME`: `SOUL.md` lives at the profile root, while active `MEMORY.md` and `USER.md` live under `memories/`.

## Fix

- Read profile-root `SOUL.md` and canonical `memories/MEMORY.md` / `memories/USER.md`.
- Expose all three with flat tab labels and keep `SOUL.md` selected first.
- Route edit, add, and delete operations back to their canonical paths.
- Seed new built-in profiles with memory files under `memories/` rather than stale root placeholders.
- Add API and UI regression coverage.
