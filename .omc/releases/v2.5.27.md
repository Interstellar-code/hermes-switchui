# v2.5.27 — Profile-safe chat and terminal workspace

**Released:** 2026-08-03
**Type:** patch release

## Summary

v2.5.27 is the consolidated release since the latest published GitHub release, v2.5.24. It includes the previously tagged v2.5.25 and v2.5.26 work plus profile-safe chat sessions, a production-hardened terminal workspace, portable chat fallback improvements, and stricter gateway and backup boundaries.

## Highlights

### Profile-safe chat

- Browse sessions by Hermes profile from the chat sidebar.
- Carry the selected profile through session lists, history, sends, clarification responses, delegations, active-run checks, rename/delete actions, local queues, and cache keys.
- Use a canonical composite session identity so equal session IDs from different profiles cannot collide.
- Fail closed when the live gateway cannot prove that it serves the requested profile instead of risking a write to the wrong profile.

### Terminal workspace

- Resize the real PTY when xterm panes change size.
- Preserve ordered input and all output under load.
- Distinguish shell exit from network disconnect and bound automatic reconnect attempts.
- Clean up SSE readers, sessions, timers, and terminal instances deterministically.
- Add accessible tabs, split panes, draggable dividers, context rename, mobile input hardening, and project working-directory choices.
- Make the secondary pane's PWD selector reuse or create a terminal without replacing the primary pane.
- Remove the Debug Analyzer panel and the background-effects toggle.

### Chat and runtime reliability

- Add multimodal portable-chat payloads and safe provider fallback behavior.
- Invalidate live gateway topology after connection changes or reprobes.
- Apply the local/auth boundary consistently across backup operations.
- Keep Matrix3D and chat session presence data aligned with scoped sessions.

### Included from v2.5.25 and v2.5.26

- Files v2 chat sidebar polish and safe SQLite downloads.
- Scalable recent-session loading and server-side older-session search.
- Update Center and Electron update controls.
- Attachment MIME preservation, delegation response recovery, accessible opening feedback, and related chat/files reliability fixes.
