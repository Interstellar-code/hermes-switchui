# v2.5.21 — Guided Self-Improve workflow

**Released:** 2026-07-21
**Type:** patch (Self-Improve UI)

## Summary

Turns Self-Improve into an analysis-first guided workflow: the screen reports the real plugin, profile, and loop state, identifies the next useful action, and makes that action available where possible.

## Changes

- Guided training and held-out scenario creation with typed checks, readable check labels, expanded scenario details, and confirmed deletion.
- A status summary that independently reports plugin availability, profile configuration, and loop state.
- A deterministic next-step engine covering bootstrap, scenario setup, metric collection, proposal, approval, observation, and healthy states.
- Actionable next steps that collect metrics, scroll to the relevant section, or copy the profile-specific bootstrap command.
- Proposal confirmation showing target, models, and estimated cost before an experiment starts.
- Clearer metric windows, experiment states, empty states, responsive layout, keyboard focus, and reduced-motion behavior.
- `react-grab` updated from 0.1.44 to 0.1.48.
