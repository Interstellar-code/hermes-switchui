# v2.5.23 — Clearer chat history and Agents drawer

**Released:** 2026-07-23
**Type:** patch release

## Summary

Chat history now separates the things people use for different purposes: general tools, to-dos, MCP calls, skills, and file activity. The new Agents drawer replaces the space-consuming Agent View panel and is launched beside the composer, where it shows the session's real sub-agent count.

## Changes

- Dedicated To-dos, MCP, Skills, and Files views with independent counts.
- Human-readable tool details: concise titles and fields first; expandable raw input and output when needed.
- Tools no longer duplicate to-do, MCP, or file calls already represented in their own views.
- Agents is now a composer-aligned robot-icon button and overlay instead of a permanent sidebar. It supports backdrop and Escape close.
- Agent badges combine persisted child sessions and live delegation events, deduping the same child between the two sources.
- Removed superseded Agent View, inspector, delegation-strip, and related unused code.
- Includes the Base UI preview-card crash fix already present in the v2.5.23 codebase.

## Verification

- Focused chat/Agents Vitest suites pass.
- Scoped ESLint and `git diff --check` pass.
- Production Vite build passes with `HERMES_SKIP_GATEWAY_BOOT=1`.
- Verified against a real session with two persisted child sessions: the Agents launcher reports `2`.
