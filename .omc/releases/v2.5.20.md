# v2.5.20 — Self-Improve profile config panel + 422 apply toast

**Released:** 2026-07-20
**Type:** patch (Self-Improve UI)

## Summary

Brings the SwitchUI Self-Improve screen in line with the `karpathy-self-improve` plugin at hermes-agent HEAD `756a20238` (PRs #172/#173/#174/#176). Built against the verified plugin API, not the draft spec — three phantom pieces in the draft were caught and corrected before implementation.

## Changes

- **Profile configuration panel** — paused state + Pause/Resume, the target file the ratchet edits (from the newest experiment row), and a CLI bootstrap hint.
- **"Takes effect" badge** on experiment cards from `live_takes_effect_at_next_session` ("Takes effect on next session" / "Live now").
- **422 apply toast** — `apiFetch` now attaches HTTP status to thrown errors; a failed patch shows "Patch failed — experiment not applied" instead of a generic message.
- **Types** — `Experiment` gains `live_takes_effect_at_next_session`, `target_relpath`, `target_profile_root` (real `SELECT *` columns).

## Corrected vs the draft spec

1. `GET /profiles/{profile}` returns only `{profile, paused}` — target file sourced from experiment rows, not the profile endpoint.
2. No `/bootstrap` HTTP route exists (CLI-only) — panel shows a hint, no dead button.
3. 422 already forwarded by the apply proxy; only the browser `apiFetch` needed the status attached — no server/plugin change.
