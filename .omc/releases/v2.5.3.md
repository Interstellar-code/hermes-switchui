# v2.5.3 — 2026-07-13

Patch release focused on runtime cleanup, correctness, and enforceable quality gates.

## Highlights

- Dashboard fallback errors now preserve their cause and safely recover once from stale internally managed authentication on idempotent GET requests.
- All seven SSE endpoints stopped emitting the invalid hop-by-hop `Connection` response header.
- The client-only workspace now uses TanStack Start SPA mode, removing the unused streaming SSR lifecycle behind the 120-second HMR cleanup warnings.
- Chat clarification cards can no longer remain stale behind the custom `MessageItem` memo comparator.
- Realtime handoff no longer renders a settled assistant and an identical streaming placeholder at the same time.
- The repository is back to a fully green lint and test baseline, with lint enforced by CI.

## Correctness fixes

- Restored raw merged-session ownership at the sidebar boundary so filtering, sorting, and cross-source counts are computed exactly once.
- Kept Retro Office gym objects collision-blocking and fully present while repositioning targets around a reachable aisle.
- Preserved the profile API contract: initial tier assignment is allowed, later tier mutation and protected-field edits are rejected.
- Fixed malformed/stale tests, unsupported JSDOM scrolling, waiting-state TTL expectations, and navigation/filtering regressions.

## Runtime hardening

- Dashboard timeouts, aborts, and network failures receive classified metadata without unsafe retries or token-cache churn.
- Caller-provided authorization and all mutations remain untouched by automatic recovery.
- SPA shell generation uses `/settings`, avoiding redirect-driven prerender behavior while retaining file API routes and the server bundle.
- Development HTTPS remains enabled; production build and internal prerender use HTTP without disabling TLS verification globally.
