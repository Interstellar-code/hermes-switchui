# v2.5.28 — Scoped workspaces and accurate Kanban

**Released:** 2026-08-03
**Type:** patch release

## Summary

v2.5.28 prevents the persistent terminal from covering non-chat workspaces,
adds explicit Hermes profile routing to Projects, and makes Tasks accurately
represent global Kanban ownership, lifecycle statuses, tenants, and assignees.

## Highlights

### Workspace layout

- Reserve the open terminal panel's height once in `WorkspaceShell` for
  non-chat routes while keeping terminal sessions mounted across navigation.
- Use parent-relative height in Tasks so the board fits the available workspace.

### Projects profile scope

- Select the Projects profile in the top bar and preserve it in
  `/projects?profile=<name>`.
- Include the profile in project query keys and every project read/write proxy.
- Fail closed for explicit profiles rather than falling back to the active one.
- Close stale drawers and dialogs when the selected profile changes.

### Kanban accuracy

- Show configured profiles, historical assignees, and Unassigned as distinct
  filter choices.
- Display visible and total counts from one current board/tenant task scope.
- Preserve historical attribution without treating old producer identities as
  profiles or tenants.
- Support the full Hermes lifecycle, including `scheduled` and `review`, in
  board, dialog, drawer, swimlane, timeline, and legacy migration paths.
- Derive the summary stripe from the same tenant-scoped tasks shown by the board.
- Label Boards as global shared Kanban rather than implying profile ownership.
