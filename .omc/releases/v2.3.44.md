# v2.3.44 — 2026-06-12

Chat hot-path performance overhaul, the long-standing "Too many re-renders" crash contained and root-caused, and the new Hermes Plugin settings section with backend config-sync.

## Highlights

### Chat performance (audit issues #212–#222, PRs #223/#224)
- Streaming no longer rebuilds the full message list every animation frame — live text reaches only the streaming bubble; one rAF smoother instead of two (#212)
- Collapsed-head windowing: threads >80 entries render the last 60 + "Show earlier messages" (#213)
- Poller/timer consolidation: SSE-gated live-progress poll, approvals backoff, one shared ticker for all tool cards (~8–10 timers → 3), getConfig TTL cache (#214)
- chat-store hygiene: append-in-order instead of full re-sort per event, per-session debounced streaming persist, unified internal-message filter (#221)
- Gateway robustness: 10s timeouts on all gateway/dashboard calls; history failures return 503 instead of faking an empty chat (#217); live-tool poll 800→1500ms (#216)
- Session-list cache desync fixed: one invalidation helper for both caches — rename/title/create update the sidebar immediately (#218)
- Session-switch realtime-buffer race fixed; dead disabled effect removed (#220)
- Composer busy state now a reactive subscription (#219); stale-render gaps in MessageItem comparator closed (#222)
- Idle network: /api/sessions poll 5s→30s (~400KB/tick), gateway activity poll 3s→10s (#225)

### "Too many re-renders" crash — contained + fixed (#225/#226)
- Error boundary captures React componentStack, persists last 3 crashes to localStorage['hermes:ui-crash-log'], Copy-details button
- Instrumentation pinpointed AnimatePresence inside AgentViewPanel; duplicate agent-id keys deduped; panel isolated in an inline boundary — a panel crash degrades to a retry card, never takes down chat

### Hermes Plugin settings section (#228, PRs #229/#230)
- New /settings section: plugin status + heartbeat age, connection info, reported settings, version-compat banner with explicit unknown state, split degraded states (plugin absent vs backend unreachable)
- Server-side register + 30s heartbeat (globalThis singleton, register-gated, backoff), allowlist-only settings mirror, auth+CSRF-guarded routes
- Frontend version resolved via __APP_VERSION__ (require() unavailable in Vite SSR); stale incompatible compat verdicts self-heal via 10-min re-register

### Self-Improve narrative UX redesign (#210, PR #211)
- Single global profile scope, merged Experiments feed, hero diff, lifecycle stepper, score context, scenario checklist

### Composer
- Paste preserves formatting (HTML→Markdown); tables render with copy button
