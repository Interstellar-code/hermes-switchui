# v2.5.14 — Projects CRUD v3

**Released:** 2026-07-19
**Type:** patch release

## Summary

Projects are now manageable from SwitchUI instead of requiring separate CLI commands. The release consumes the Hermes Agent 0.18.3 dashboard Projects CRUD API and preserves the Projects v2 activity/enrichment UI.

## What shipped

- Create projects and edit name, description, icon, color, and board binding.
- Add, remove, and select a primary folder.
- Set the active project pointer.
- Archive and restore projects.
- Permanently delete archived projects with a two-step confirmation.
- Profile-scoped BFF requests so each active SwitchUI profile reads the matching Hermes Projects database.
- Mutation errors are shown in the screen, controls are disabled while a mutation is pending, and project queries invalidate after successful writes.

## Compatibility and safety

- Hard deletion remains archived-only and is enforced atomically by Hermes Agent.
- Duplicate slugs retain Hermes Agent's existing auto-suffix behavior.
- JSON `null` remains rejected for PATCH fields; empty strings are used to clear supported values.
- Existing Projects v2 task counts, board enrichment, last-activity data, and Activity tab remain available.
