# v2.5.29 — Profile-bound chat sessions

**Released:** 2026-08-04
**Type:** patch release

## Summary

v2.5.29 makes Chat profile selection session-scoped: choose a profile before
the first message, then keep that session bound to the same profile without
changing or restarting the gateway.

## Highlights

### Session profile binding

- Enable profile selection only for new chats.
- Show the bound profile as read-only after a session starts.
- Preserve explicit profile scope in desktop and mobile navigation, direct
  session reads, and history queries.

### Restart behavior

- Remove the gateway-wide profile activation action from the Chat composer.
- Avoid restart warnings when selecting a profile for a new multiplexed chat.
- Use `hermes gateway restart` in the restart banner.
- Clear obsolete persisted warnings from the former Chat activation flow.
