# v2.5.26 — Chat performance, Update Center, and reliability polish

**Released:** 2026-08-01
**Type:** patch release

## Summary

v2.5.26 combines the product work completed after v2.5.25 into one release: scalable chat-session loading and search, lower-cost history/tool recovery, an integrated Update Center for source and desktop installations, and focused chat, files, attachment, and delegation reliability fixes.

## Changes

### Chat performance and UX

- Loads a recent 200-session page instead of transferring and deriving the full session collection during normal navigation.
- Fetches an older active session directly, preserving deep links while keeping the common path bounded.
- Uses server-side session search so older conversations remain discoverable.
- Updates a sent-to session in the shared cache immediately instead of refetching the complete session list on completion.
- Reduces session safety polling, removes the redundant idle-navigation history refresh, and bounds live-tool recovery to the newest 100 messages.
- Shows accessible `Opening…` feedback as soon as a different session is selected.

### Update Center

- Adds a Settings section and discreet in-app entry point for SwitchUI and Hermes Agent update status.
- Shows current and target versions or commits, local blocking files, confirmation prompts, and update progress.
- Supports Electron download and install/restart actions without native modal interruptions.
- Restricts workspace Git updates to verified fast-forwards and uses Hermes Agent's strict updater API for its update lifecycle.

### Reliability polish

- Preserves image MIME types through the attachment send path.
- Displays delegation final responses even when a child agent produced no tool activity.
- Copies paths using the actual workspace root.
- Permits supported `data:` connection flows in the application CSP.

## Performance evidence

- Full session response: approximately 1.21 MB and 1.43 seconds in the release probe.
- Normal recent page: approximately 173 KB and 44 ms warm in the same probe.
- Direct active-session lookup: approximately 453 bytes and 5 ms.
- Dashboard pagination was verified to return the newest tail on a 601-message session.
